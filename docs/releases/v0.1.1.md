# TwinCAT Knowledge MCP 0.1.1 preview

This is the first private software preview release. It provides the existing
read-only stdio server and operator CLI, with recovery of abandoned loader
caches after a process terminates unexpectedly.

## Changes

- New private cache generations record the process that owns them before any
  corpus data is copied. The next package load removes marked generations only
  after confirming that their owner has ended.
- Active readers, inaccessible owners, reused live process IDs, unmarked legacy
  caches, redirected paths and unknown contents are preserved. Normal shutdown
  still closes the index and removes that reader's own temporary generation.
- Package metadata, CLI output and MCP server identity report version 0.1.1.
- Process-abort, concurrent-reader, partial-cache, failed-cleanup and redirected
  directory regressions cover recovery without touching source packages.

## Packages and installation

The release provides `twincat_knowledge-0.1.1-py3-none-any.whl`, the corresponding
source archive, the dependency lock and SHA-256 checksums. These are software
packages. Documentation corpora, operator profiles, credentials and databases
are not included.

Verify downloads against `SHA256SUMS.txt`. Install the wheel with Python 3.12 or
newer in a separate environment, for example:

```sh
uv tool install --python 3.12 ./twincat_knowledge-0.1.1-py3-none-any.whl
twincat-knowledge --version
twincat-knowledge serve --transport stdio --config /absolute/path/config.toml
```

For an existing environment, stop its MCP server and install the wheel with
`uv pip install --python /absolute/path/to/environment/python --upgrade
./twincat_knowledge-0.1.1-py3-none-any.whl`. Restart the client-owned server after
the upgrade. Existing snapshot selections and source packages need no migration.

## Rollback and limitations

Keep the previous software installation and operator configuration before an
upgrade. Roll back by stopping the server, reinstalling the previous software
package or source revision, and restarting it with the unchanged configuration.
No schema or corpus conversion is introduced by this release.

Legacy caches without an owner marker are intentionally retained. An operator
can remove verified abandoned legacy copies after their readers stop. Each live
reader still needs a private verified corpus copy; this release addresses
accumulation after termination, not corpus startup time or deduplication.

The MCP protocol profile remains `2026-07-28`, with four read-only documentation
tools. Windows and Linux are the supported CI targets on CPython 3.12.10 and
3.13.12. Release verification records the checks actually completed; a successful
synthetic test does not establish every host's compatibility or InfoSys coverage.
This preview does not provide PLC access, engineering writes, runtime control,
HTTP serving or a bundled documentation corpus. Repository visibility and the
existing software licensing position are unchanged.
